# HALLAZGOS

## Flujo observado de web

No existe `docs/ENDPOINTS.md` en el workspace. Lo siguiente describe el contrato observado en el cliente; no representa un contrato acordado con los servicios.

- Login: `POST http://localhost:8080/auth/login` con `username`, `password` y `client`. Si `response.data.token` existe, el cliente guarda token, usuario y preferencias en `localStorage` y navega a `/dashboard`. Evidencia: [web/src/app/login/login.component.ts:41](web/src/app/login/login.component.ts#L41), [web/src/app/login/login.component.ts:46](web/src/app/login/login.component.ts#L46), [web/src/app/login/login.component.ts:47](web/src/app/login/login.component.ts#L47), [web/src/app/login/login.component.ts:50](web/src/app/login/login.component.ts#L50).
- Dashboard: lee token y usuario de `localStorage`; sin token navega a `/login`. Con token hace `GET http://localhost:8000/api/tasks?owner=<username>` con `Authorization: Bearer <token>`, filtra tareas `ARCHIVED`, prepara etiquetas y ordena la lista. Evidencia: [web/src/app/dashboard/dashboard.component.ts:36](web/src/app/dashboard/dashboard.component.ts#L36), [web/src/app/dashboard/dashboard.component.ts:39](web/src/app/dashboard/dashboard.component.ts#L39), [web/src/app/dashboard/dashboard.component.ts:43](web/src/app/dashboard/dashboard.component.ts#L43), [web/src/app/dashboard/dashboard.component.ts:49](web/src/app/dashboard/dashboard.component.ts#L49), [web/src/app/dashboard/dashboard.component.ts:54](web/src/app/dashboard/dashboard.component.ts#L54).
- Cierre de sesión: elimina token y usuario localmente y navega a `/login`; no se observa una llamada de logout al servidor. Evidencia: [web/src/app/dashboard/dashboard.component.ts:74](web/src/app/dashboard/dashboard.component.ts#L74), [web/src/app/dashboard/dashboard.component.ts:75](web/src/app/dashboard/dashboard.component.ts#L75), [web/src/app/dashboard/dashboard.component.ts:77](web/src/app/dashboard/dashboard.component.ts#L77).
